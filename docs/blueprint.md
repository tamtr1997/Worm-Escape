# **App Name**: Worm Escape

## Core Features:

- Level Creation: Allow users to create custom levels by coloring grids to form the level's components.
- Object Creation: Translate colored grid patterns into 3D objects, including a lock frame (immovable), lock space, movable blocks with color selection, and a key block crucial for winning.
- Level Saving: Enable users to save created levels locally or to the browser to be played later.
- Level Selection: Provide a home screen where players can select and play created levels.
- Block Movement: Implement the ability to move the colored blocks within the confines of the lock space.
- Objective Tracking: Track the key block's height and determine when the player wins by creating enough space for the worm to escape.

## Style Guidelines:

- Primary color: Dark violet (#483D8B), lending a sophisticated and mysterious ambiance to the game interface.
- Background color: Light violet (#E6E6FA), maintains visual consistency with the primary color while providing sufficient contrast
- Accent color: Sky blue (#87CEEB), strategically positioned for calls to action.
- Font: 'Inter' sans-serif for a clean and modern look suitable for both headings and body text
